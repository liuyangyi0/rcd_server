## 页面变更

- 主流程统一为“修改 → 校验 → 保存 → 手动重启”。仅保留“校验当前草稿”“保存到下级”两项主要操作，参数合并自动包含在校验中，不再单独生成草稿。
- 默认展示常用参数；下拉按类别筛选，搜索覆盖全部参数。日志内部队列/缓存项不默认铺满页面；技术字段放到说明后，默认值和只读项单独标识。
- 校验结果紧邻主操作区，区分“配置错误不可保存”和“点表提示可以保存”；提示内容不替换成泛化文案。
- 原文、导入/下载/备份、文件版本分区折叠；未保存草稿载入文件或备份需确认。合并失败、内容超限、旧来源/文件 revision 或后台刷新不能静默丢弃草稿。
- 修正窄屏顶栏挤出视口的问题，保留密码修改和退出操作。
