## 修复内容

| 范围 | 问题与修复 |
| --- | --- |
| 告警与审计 | “全部”无法保持选中：改为独立 URL 状态 `state=all`，请求时转换为不限制状态。最近一小时等相对时间窗口不再固定结束时间，定期和手动刷新会推进起始时间；自定义历史区间仍保持固定。 |
| 下级配置 | 原始文本逐字编辑会触发准备请求并禁用输入：准备请求防抖，后台准备与提交分别管理忙碌状态。离开页面后返回可恢复同一来源、来源 revision 和文件的内存草稿，保留原文件 CAS 基线；成功提交、明确丢弃或退出登录才清理，不存入浏览器持久存储。 |
| 状态输入 | 保存旧行时使用最新整份配置中的对应映射，不能用旧表格覆盖已改变的映射；映射已经删除时拒绝从旧行重新创建。 |
| 计算草稿 | 异步保存、导入或重载的旧响应不能清空、覆盖新一轮编辑；切页后的旧响应有实例和代次栅栏。 |
| 计算结果与模式 | 切换筛选不再把上一次查询的占位结果冒充新结果；下级模式操作清理旧成功提示，优先展示当前错误或处理中状态。 |
| 历史版本恢复 | 没有活动计算配置时仍可恢复历史版本。恢复接口仅在该场景接受精确强 ETag `If-Match: "0"`；状态接口返回对应 ETag。其他写接口的 revision 校验未放宽，弱 ETag 和未加引号的 `0` 不被当作该特例。 |
| 弹窗 | 自动刷新引发父组件重渲染时，不再反复运行焦点初始化；保持当前输入焦点，关闭时取消尚未执行的焦点任务，关闭回调使用最新引用。 |
| 日志实时刷新 | 按来源合并 SSE 刷新，每秒至多触发一次，不取消仍在执行的慢查询，保留尾随刷新并在卸载时清理计时器。 |
| 命令记录 | 结果缩减导致当前页为空时仍保留分页并回到有效末页；浏览器前进、后退后搜索框与 URL 一致。 |
| 运行总览 | 使用精确状态匹配，`Inactive` 不再误判为正常；部分接口失败、待确认数据不再显示成零条或“全部正常”，缓存时间使用实际数据更新时间；版本关注入口不再仅筛出失败项而遗漏其他异常。 |

使用说明同步更新：`guides/lower-operations.md`、`guides/web-login-and-usability.md`、`reference/rest-api.md`。
