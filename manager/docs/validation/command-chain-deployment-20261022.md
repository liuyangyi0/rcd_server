## 新参数怎么用

入口：**下级 OPC → 目标物理来源 → 运维 → 配置 → config.toml → 参数设置**，搜索 `command_interval_ms`，字段为“控制命令最小间隔（ms）”。

三台当前均保持原配置，缺省 **0ms**，没有替使用人选择 500ms 等值。允许 0–60000 的整数；修改后生成草稿、校验、保存，再明确重启该下级才生效。一个下级配置一个值，各串口独立执行；作用于上一条控制事务结束到下一条首次发送，不改变普通轮询、同条重试或有效 `00 50 50` 立即停止的规则。等待不延长命令期限，详见[下级运维说明](../guides/lower-operations.md#控制命令最小发送间隔)。
