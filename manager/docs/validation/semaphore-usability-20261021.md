| 任务列表读取失败会连带阻止当前详情更新，旧错误恢复后仍残留 | 列表和详情独立请求，旧响应/错误不能覆盖新结果；详情失败明确标注历史结果，恢复后清除。显示最后确认时间，后台轮询不切换整页加载态；登录失效停止自动轮询，离开页面不残留计时器 |
| 详情抽屉遮住外侧刷新按钮，抽屉内没有刷新入口 | 新增“刷新任务详情”，只GET原任务，不创建、重投、安装或重启 |
| 历史记录把重复安装次数称为版本数，当前映像也可被误点恢复 | 改为“条安装记录”；成功近期快照的实际运行SHA（停止时用磁盘SHA）与历史包相同则提示已是当前程序版本。历史读取失败时禁用恢复入口；不以相同版本标签替代映像比较 |
