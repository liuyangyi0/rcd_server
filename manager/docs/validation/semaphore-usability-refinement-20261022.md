## 意见与实际修改

| 角度 | 确认的问题 | 已实施 |
| --- | --- | --- |
| 现场接入 | 更换浏览器或丢失本机引用后找不到原首装作业 | 设备页增加“接入与首装记录”，从服务端分页、搜索、筛选；“查看原作业”按原ID读取，不重新登记或安装 |
| 现场接入 | 失败只显示“检查失败”，禁用按钮没有解释 | 主表显示失败原因及原检查日志入口；首次安装、检查占用、绑定及权限限制有可见说明 |
| 现场接入 | 首装流程缺少当前步骤、下一步和版本加载总量 | 显示接入/首装进度、对应状态下一步提示、版本已加载数与页数、重新读取选项 |
| 页面信息 | 长版本号撑高表格；失败时缓存的运行状态仍显示绿色 | 版本摘要单行省略，保留完整提示和详情；检查失败、过期或列表读取失败时标记“上次：…”并取消绿色，不抹掉历史版本 |
| 列表交互 | 多个列表先改页码再请求，失败后旧行配新页码，再翻页跳页 | 设备、软件包、任务、组件历史及接入记录仅在成功后提交页码，失败保留旧页并说明，重试原请求页 |
| 发布交互 | 上传到提交时才发现格式/大小错误，多文件拖入可能保留旧文件 | 选择时检查256 MiB和扩展名、明确已选文件及大小；多文件清旧选择；不自动上传、不替代服务端内容校验 |
| 发布交互 | 确认页长期开着，已过期目标仍显示可执行 | 本地时钟跨180秒后自动禁用；任一已选目标失效时阻止整次确认，不静默丢掉该目标后发布其他机器 |
| 发布交互 | 取消排队任务一键执行，确认框与详情层级冲突 | 先展示动作、目标及原操作号，明确确认后校验ID/revision；“保留任务”不取消、不关闭原详情，可再次打开确认框 |
| 发布交互 | 手机任务详情固定宽度；软件种类表单缺少示例 | 窄屏详情全宽，长操作号换行；种类表单补示例及受控路径/服务预览，不允许任意安装命令 |
| 异常恢复 | 操作登记后异常仍提示“未触发发布”，容易诱发重复提交 | 操作专用错误明确“结果待确认”；已知原操作号时返回公开`operation_id`，升级/启停页提供原任务链接并保留原请求 |
| 查找与诊断 | 按主机IP或发布编号找不到任务；磁盘检查失败原因被丢弃 | 搜索支持主机名/IP、发布号、任务号及操作者；保留磁盘错误和可信运行事实，不把磁盘版本冒充运行版本 |
| 异步边界 | 迟到绑定/发布响应可污染新上下文，入口读取失败只能整页刷新 | 增强项目、目标及请求代次隔离；项目入口支持只读重试和登录失效提示，离开后旧响应不能把用户导航回去 |

接入列表新增可选`page/page_size/q/state`及`total_pages`，稳定排序；不带分页参数时保留原全量行为，避免旧维护工具漏检未结束作业。没有修改既有认证、维护锁、revision、幂等编号、未知结果禁止重投及人为停止语义。
