# 数据流监视

入口为管理网页地址后加 `/#/flow`。登录页和管理导航均有“数据流监视”入口。该页面免登录，只提供查看、筛选、全屏和暂停视觉动画；进入管理页面仍需原有账号。

## 查看内容

- 左侧为当前逻辑组的物理来源，显示 OPC 连接、订阅活动、串口和站点状态。点击来源，查看全部已展示站点以及只读采集点的值、类型、质量和源时间。
- 中间显示逻辑组、默认来源、Session 选源规则和中央计算状态。圆环、刻度、数据列及环带扫描线持续运动；文字和操作目标保持固定。
- 右侧为当前管理端的真实 OPC Session，显示该 Session 在当前组中选择的来源、订阅数量及监控项数量。通道分离后保留的 Session 单独标记，关闭或超时后从画面移除。
- 没有上级 Session 时，右侧显示“最新样本缓存、尚未向客户端发送”。缓存流动仅跟随收到的采集更新，不表示已发送给客户端。
- 底部显示页面打开后的状态变化、最近60次快照的样本增量、选中来源及控制队列总数。控制步骤文字只说明流程，不推断某条命令的发送阶段或设备执行结果。

每屏最多展示4个来源和4个 Session，可翻页；切换逻辑组仅改变查看范围，不改变业务默认源或任何 Session 的选择。页面只反映当前管理端，不汇总另外两台管理端的会话。

## 动画与真实状态

| 表现 | 数据依据 |
| --- | --- |
| 圆环、刻度、环带数据列、扫描线、向上漂浮的微尘、标题和边框扫光 | 视觉装饰，不表示通信成功 |
| 来源流动粒子（向汇聚点加速的彗尾光点） | 管理端实际接受的采集样本计数发生变化；旧 epoch、未知点和不合格样本不计入 |
| 汇聚点脉冲环 | 该来源的样本计数在最近一次快照中增加；每次增加触发一次 |
| 环带径向光点、环带亮度与转速 | 按当前页实际流动的来源和 Session 比例变化；无活动时只保留低速装饰旋转 |
| 站点分支异常 | 使用现有 CommunicationState 0–5 规则，检查来源连接、状态新鲜度、epoch及拓扑身份；异常站点指示灯呼吸闪烁 |
| Session 输出流动、客户端端口脉冲环 | 该 Session 的订阅生成了新的数据通知；不把 KeepAlive、连接存在或最后访问时间当作数据通知 |
| 来源卡、Session 卡扫光及高亮边 | 与卡片上“正在收到更新”“正在生成通知”同一判断 |
| 断线、停用、无变化 | 对应数据流淡出并停止；监视断开或过期时整幅画面转为灰色，轨道光点、径向光点和脉冲全部熄灭；仍保留可查看的最后快照 |

粒子为经过缩放的活动示意，不逐一对应报文、变量、字节数或某站点的每次串口交换。来源粒子有约3秒的视觉衰减。订阅统计表示管理端**生成通知**，不证明客户端已收到，也不证明物理设备执行成功。链路活动面板右上角数字为最近一次快照间隔收到的采集样本数。

公共状态每秒读取一次，点位详情每2秒读取一次，每页20点。监视请求失败或5秒未收到快照时，页面明确显示断开/过期，并停止数据粒子；恢复后自动继续。暂停按钮只暂停视觉动画（含页面上的装饰动效），数据读取和采集继续；暂停时画面保留当前实际流动状态的静止帧。系统设置“减少动态效果”时，旋转、粒子位移和页面装饰动效保持静止。画面以最高60帧绘制，单帧绘制开销过高时自动降为30帧。

## 只读边界

仅以下两个新接口允许匿名 GET/HEAD：

- `/api/v1/public/flow`：限定字段的内存快照，多名观看者共用每秒一次的缓存。
- `/api/v1/public/flow/points`：按来源、串口、站点、名称分页读取只读业务点。命令点和可写点不在此列表内。

不公开来源凭据、配置原文、原始 OPC Session ID、普通日志、命令报文或审计详情。名称、地址、站点、路由和读取到的点位值按本页用途公开。原管理接口和所有修改操作继续要求登录，不新增任何公共写接口。

该功能不改变 OPC NodeId、串口时序、重试、ACK、采样参数、选源或计算语义，不启动额外串口读取者，也不保存点值历史。
