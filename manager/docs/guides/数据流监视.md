# 数据流监视

入口为管理网页地址后加 `/#/flow`。登录页和管理导航均有“数据流监视”入口。该页面免登录，只提供查看、筛选、全屏和暂停视觉动画；进入管理页面仍需原有账号。

标题栏右侧可在“管线”和“矩阵”两种视图间切换，两者读取同一份快照、遵循同一套真实性规则，只是画法不同。所选视图记在当前浏览器中；地址加 `?view=matrix` 或 `?view=pipeline`（如 `/#/flow?view=matrix`）可固定打开某一视图，适合大屏。默认为管线视图。

## 管线视图

- 左侧为当前逻辑组的物理来源卡片：OPC 状态、最近一次快照的样本数及近30次快照的样本趋势，下方每个串口一行（串口名、每个站点一个圆点、正常站数/总站数）。点击来源，查看全部已展示站点以及只读采集点的值、类型、质量和源时间。
- 中间框内为当前管理端的处理过程：①样本缓存，每个来源一个缓存槽；②会话选源，每个 Session 一个节点，只与它在当前组实际选择的来源槽相连；③中央计算，由默认来源供数，环形表显示 Good 与其他结果的比例，结果经共享总线并入各 Session 的输出。
- 右侧为当前管理端的真实 OPC Session 卡片：选择的来源、订阅和监控项数量、最近一次快照生成的通知数及趋势。通道分离后保留的 Session 单独标记，关闭或超时后从画面移除。
- 没有上级 Session 时，右侧显示“最新样本缓存、尚未向客户端发送”。缓存流动仅跟随收到的采集更新，不表示已发送给客户端。
- 底部四块：
  - 实时事件：页面打开后的来源连接、站点状态、选源和会话变化，按类型标注；绿色为恢复或接入，红色为断开或站点异常。
  - 链路活动：最近60次快照的采集样本数（柱）和生成通知数（线，各按自身峰值缩放），以及峰值、均值和近期有更新的来源数。
  - 站点概况：当前组各状态站点数量及在线来源数；鼠标悬停在来源卡上时改为显示该来源的站点和异常站点。
  - 控制队列：待处理命令总数及最近快照的队列深度趋势。“接收 → 排队 → 发送 → ACK”只说明流程，不推断某条命令所处阶段或设备执行结果。

每屏最多展示4个来源和4个 Session，可翻页；切换逻辑组仅改变查看范围，不改变业务默认源或任何 Session 的选择。选择的来源不在当前页时，Session 节点标注“其他页”。页面只反映当前管理端，不汇总另外两台管理端的会话。

## 线路与路由

每条串口线从来源卡上对应的串口行引出，汇入该来源的缓存槽：有几个串口就有几条线。窗口较矮时每张卡最多显示3行（较高时5行），超出的串口合并为“+N 串口”一行和一条线。串口线状态按该串口站点的 CommunicationState 判断：有通信正常站点为青色，可承载数据包；全部站点通信异常或串口未打开为琥珀色虚线；没有通信正常站点（未知、停用或下级离线）为暗灰线。来源目录冲突时全部串口线为琥珀色虚线；来源停用为灰色虚线；OPC 未连接为在中途断开的红色虚线和“×”。

缓存槽到 Session 节点的亮线就是该 Session 在当前组的实际选源；其余可能的组合以淡虚线示意。画面结构（边框、线路、卡片）使用中性灰蓝，只有实际流动的数据线、数据包和关键数字使用天蓝强调；红、琥珀和灰色只表示故障或停用。鼠标悬停在来源卡上时，该来源及选择它的 Session 保持高亮，其余变暗；悬停在 Session 卡上时，高亮它所选的来源。

## 管线视图的动画与真实状态

| 表现 | 数据依据 |
| --- | --- |
| 打开页面时的启动动画（边框描出、线路从卡片连向中间、数字从 0 滚动到实际值）、管理端边框扫描线、框内点阵与刻度、淡虚线组合、标题栏和卡片扫光 | 视觉装饰，不表示通信成功 |
| 指标栏底部的进度细线、扫过画面的淡光带 | 每收到一次快照触发一次；监视断开或过期时停止 |
| 数字滚动和短暂高亮 | 对应数值在新快照中发生变化 |
| 串口线上的数据包（带彗尾，落入缓存槽） | 该来源在最近一次快照中实际接受的采集样本计数增加；每次增加发射一组，数量按样本数的对数缩放（3–18个，且每条可承载的串口线至少一个）；旧 epoch、未知点和不合格样本不计入。快照只有来源级样本计数，没有逐串口计数，因此数据包平均分配到该来源有通信正常站点的串口线上，不表示各串口的实际报文比例 |
| 缓存槽的电平条、亮边和写入扫光 | 与来源卡“正在收到更新”同一判断，约3秒无新数据后熄灭；每批数据包落入时扫过一次 |
| 活动线路上流动的光波 | 与对应卡片“正在收到更新”“正在生成通知”同一判断 |
| 串口线琥珀色告警脉冲（恢复时为绿色）、来源卡和串口行闪烁 | 该串口上异常或离线的站点数比上一快照增加（减少）；来源卡在故障状态或异常站点数变化时闪烁，切换页面、逻辑组或视图时不闪烁 |
| 红色断线回缩与火花、重新连通时从卡片亮回缓存槽 | 来源 OPC 连接在快照之间断开或恢复；断开时清除该来源在途的数据包 |
| 选源线、Session 节点和输出线上的数据包，节点上的转发指示和写入扫光，客户端端口的波纹与火花 | 该 Session 的订阅生成了新的数据通知；不把 KeepAlive、连接存在或最后访问时间当作数据通知。数据包从所选来源的缓存槽出发，比快照晚约1秒，以便在画面上衔接输入流向 |
| 中央计算供数线、环形表亮起和共享总线脉冲 | 快照中的计算求值时间发生变化；首次打开页面不触发。环形表比例为最近一次的 Good 与其他结果数 |
| 卡片上的“+N”和趋势线 | 最近一次及近30次快照间隔的实际样本数或生成通知数 |
| 站点圆点 | 使用现有 CommunicationState 0–5 规则，检查来源连接、状态新鲜度、epoch及拓扑身份；异常站点指示灯呼吸闪烁 |
| 断线、停用、无变化 | 对应线路变暗并停止发射数据包；监视断开或过期时整幅画面转为灰色，数据包、波纹和火花全部清除；仍保留可查看的最后快照 |

数据包为经过缩放的活动示意，不逐一对应报文、变量、字节数或某站点的每次串口交换。订阅统计表示管理端**生成通知**，不证明客户端已收到，也不证明物理设备执行成功。链路活动面板右上角数字为最近一次快照间隔收到的采集样本数。

公共状态每秒读取一次，点位详情每2秒读取一次，每页20点。管理端的快照缓存1秒，重复收到同一快照（生成时间相同）不计为新快照，不产生活动或轨迹列。监视请求失败或5秒未收到快照时，页面明确显示断开/过期，并停止数据包；恢复后自动继续。暂停按钮只暂停视觉动画（含页面上的装饰动效），数据读取和采集继续；暂停时画面定格，不再发射新的数据包，新出现的卡片和站点直接以最终状态显示；暂停期间断开的来源，其在途数据包同样清除。系统设置“减少动态效果”时不发射数据包，活动线路以静止的发光和缓存槽电平表示，卡片照常显示“+N”。画面以最高60帧绘制，单帧绘制开销过高时自动降为30帧。

## 矩阵视图

矩阵视图回答两个问题：谁从谁取数（路由矩阵），以及流量随时间怎么变（吞吐轨迹）。一次查看一个逻辑组。

- 左侧为当前组的来源标签，点击查看站点和点位（与管线视图的来源详情相同）。左上角“合计”为最近一次快照间隔全部来源的采集样本数和全部 Session 生成的通知数。
- 吞吐轨迹：每个来源一行，每列对应一次收到的快照，最右侧 NOW 为最新，随新快照向左移动。柱高按该次样本数的对数、相对屏幕内最大值缩放；小点表示该次没有新样本，红色短横表示 OPC 未连接，灰点表示停用。上方合计图为全部来源样本数（柱）和全部 Session 通知数（线），各按自身峰值缩放。轨迹从打开页面开始在浏览器内存中累积，最多90次快照，刷新即清空；“记录起点”竖线标出历史起点（打开页面或管理端重启后重新开始），不回填、不写数据库。
- 路由矩阵（管理端框内）：行为当前组来源，列为上级 Session，最右一列为中央计算。菱形交叉点为该 Session 在当前组实际选择的来源，圆形为中央计算使用的默认来源，其余交叉点以小“+”示意可选组合。列顶为 Session 标签（选源、订阅、监控项、最近通知数及趋势）；Session 较多、列间距不足时改为竖排名称，完整信息见悬停提示。每页最多16个 Session 列；来源每页5行，窗口较高时8行；均可翻页。所选来源不在当前页时，该列底部标注“↑ 来源”，数据从列底升起。
- 底部左侧为事件时间线：事件标记在它所属快照的位置，与上方吞吐轨迹对齐；下方列出最近3条事件，并显示待处理命令总数。底部右侧为站点阵列：当前组每个站点一个方格，按来源和串口分组，颜色沿用站点状态规则；状态变化时方格翻转，异常站点呼吸闪烁；点击来源组打开来源详情。
- 悬停来源标签或站点阵列中的来源组时，该来源行和选择它的列保持高亮；悬停 Session 标签时，高亮它所选的来源。

| 表现 | 数据依据 |
| --- | --- |
| 启动动画（边框描出、行线展开、列线升起、交叉点出现）、框内点阵与刻度、扫描线、小“+”交叉点 | 视觉装饰，不表示通信成功 |
| 吞吐轨迹新增一列并向左滑动，NOW 线闪亮 | 每收到一次快照触发一次；监视断开或过期时停止，轨迹定格并转灰 |
| 行线上的数据包 | 该来源在最近一次快照中的采集样本计数增加，数量按对数缩放（3–18个）；表示数据进入管理端缓存，与是否有 Session 选择该来源无关 |
| 沿所选行进入、在交叉点转弯（天蓝变为淡蓝）并升至列顶的数据包，交叉点闭合脉冲，列顶波纹与火花 | 该 Session 生成了新的数据通知；当前组未选择来源的 Session 只点亮列顶，不画来源路径 |
| 交叉点沿列从旧来源滑到新来源 | 该 Session 在当前组的选源在快照之间发生变化；中央计算列在默认来源变化时同样滑动 |
| 计算列数据包、列顶点亮和共享结果总线脉冲 | 快照中的计算求值时间发生变化；首次打开页面不触发 |
| 行线红色回缩与火花、重新连通时整行亮起 | 来源 OPC 连接在快照之间断开或恢复；断开时清除该来源在途的数据包，包括经它转发给 Session 的数据包 |
| 行线琥珀色告警脉冲（恢复时为绿色）、来源标签闪烁 | 该来源异常或离线的站点数比上一快照增加（减少）；OPC 断开或恢复时来源标签也闪烁。切换页面、逻辑组或视图时不闪烁 |

数据包同样为经过缩放的活动示意。读取周期、断开/过期、暂停和“减少动态效果”的处理与管线视图相同；暂停时吞吐轨迹仍按收到的快照更新，只是不再滑动。

## 只读边界

仅以下两个新接口允许匿名 GET/HEAD：

- `/api/v1/public/flow`：限定字段的内存快照，多名观看者共用每秒一次的缓存。
- `/api/v1/public/flow/points`：按来源、串口、站点、名称分页读取只读业务点。命令点和可写点不在此列表内。

不公开来源凭据、配置原文、原始 OPC Session ID、普通日志、命令报文或审计详情。名称、地址、站点、路由和读取到的点位值按本页用途公开。原管理接口和所有修改操作继续要求登录，不新增任何公共写接口。

该功能不改变 OPC NodeId、串口时序、重试、ACK、采样参数、选源或计算语义，不启动额外串口读取者，也不保存点值历史。
