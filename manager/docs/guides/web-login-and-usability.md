# 网页登录与操作优化

本次只变更管理端 Web 与管理 API，不改变 OPC 安全策略、4840/4841/8087 端口，也不修改串口轮询。

## 登录和密码

测试环境按指定初始账号 `admin`、密码 `admin` 初始化。打开 `http://192.168.10.46:8087/` 登录；右上角可修改密码或退出。

登录有效期为 8 小时。退出、修改密码或管理端重启后需重新登录；修改密码使所有网页会话失效。密码只保存加盐哈希，网页不保存明文密码。管理审计中的操作者由登录账号和客户端 IP 确定，不再使用浏览器自填名称。

管理 API、CSV 导出、诊断下载、metrics 和 SSE 均要求登录；健康探针与下级 HTTP 日志接收维持独立通道。OPC 客户端不需要网页登录。

注意：当前仍使用 HTTP，账号密码在网络传输时没有 TLS 加密。`admin/admin` 是弱密码，仅适合当前隔离测试网络，建议登录后修改。此次没有改变 OPC 匿名控制的既有配置。

## 筛选和分页

- 日志页先选下级来源，再选串口和站点；更换串口会清除旧站点筛选。历史链接中的旧串口、站点仍可显示。
- 设备版本页串口选项来自完整拓扑，不再只显示当前表格页内的串口。
- 点位、计算结果、设备版本、命令、日志及审计支持每页 25/50/100/200 条，显示总条数、当前页/总页数，并可输入页码跳转。更改每页条数回到第一页。
- 日志刷新会推进“最近一小时”等相对时间窗口；翻页保持查询时间。开始晚于结束时提示纠正，不发出无效查询。
- 告警/审计的相对时间范围不固定结束时间，轮询和手动刷新可以看到页面打开后新增的记录；自定义历史范围保持不动。告警状态“全部”包含已恢复和未恢复，不等同于默认的“未恢复”。
- 命令记录的越界空页仍保留分页及“返回末页”；浏览器前进/后退会同步搜索框。计算结果切换筛选时先加载新结果，不将旧列表冒充新条件的数据。
- 下级日志等级设置折叠展示，明确区分“查看等级筛选”和“修改下级日志配置”。
- 日志推送只合并触发相关查询，不反复取消在途读取；后台刷新不抢走弹窗中的输入焦点。总览读取失败显示未确认，不把未知状态计为零异常。
- 计算草稿未保存文本在页签/页面切换后保留；服务端草稿变化时提示版本冲突，不覆盖本地编辑。退出或登录过期会清除编辑缓存，应及时保存或导出。
- 复制失败时提供可选文本；新页面回到顶部。配置导入和重载前提示覆盖风险。
- 来源、分组及选源弹窗关闭后，已经提交的请求仍可能完成；界面明确提示这一点，旧响应不会关闭新打开的编辑器。编辑中的 revision 保持原确认版本，后台刷新不会替旧意图自动换成新版本。
- 设备版本批量操作遇到 409 时停止该来源的剩余修改，要求刷新核对，不自动换 revision 重投；缺少目标站点的查询响应显示“待确认”，不冒充完成。切换筛选期间不保留可写的旧行。
- 点位普通浏览和双来源比较的空末页仍提供分页恢复入口。首次配置向导提交期间冻结参数并阻止重复点击；已创建分组但来源失败时保留部分结果，可核对后修正来源继续。

## 首次部署和恢复

首次启动可用 `RCD_WEB_USERNAME` 与 `RCD_WEB_PASSWORD` 初始化。数据库已有账号时忽略这些环境变量，因此服务重启不会把已修改的密码改回初始密码。

未指定初始密码的新部署会生成随机密码，存于数据目录 `web-initial-password.txt`，文件权限限制为服务账号；首次登录要求修改，修改后删除该文件。

忘记密码时，先停止管理服务，再设置 `RCD_WEB_PASSWORD` 为至少 8 字节的新密码，执行：

```sh
RcdManager web-reset-password --data-dir=/实际数据目录
```

随后清除该环境变量并启动服务。必须停止旧进程后执行，以免旧进程仍持有原凭据缓存。

本版本包含 SQLite migration。回退旧二进制时须同时恢复部署前配套数据库，不能把新 schema 数据库直接交给旧程序。回退会丢弃备份之后的管理配置/审计变化，应先另存当前数据库。
