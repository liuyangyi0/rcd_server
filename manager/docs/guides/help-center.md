## 查找和复制

- 搜索按多个关键词与分类交集查全文、参数、NodeId和示例；可清除筛选，支持浏览器前进/后退及主题直达链接，例如 `/#/help?topic=platform`。
- 节点旁“复制节点”只复制完整 NodeId；代码块复制完整示例，不复制标题和解释。浏览器禁止自动复制时显示可选中的原文。
- 带 `<组ID>` 等占位符的模板必须替换；String、UInt32、UInt64 不能混用。复制不是执行。
- `SelectionRevision` 用于当前 Session 选源；`TransmitStatus.revision` 用于目标通信来源的发送快照，不可互换。
- 完整39项 JSON 是格式示例，包含定长演示原始块，必须替换当前 revision 与所有实际业务值，不能直接投现场。
