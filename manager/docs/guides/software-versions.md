# 软件版本总览

入口：登录管理网页，打开左侧“系统信息”，查看“软件版本总览”。此功能不是“设备版本”页：设备版本指通信模块、PLC 固件，这里查看管理端、下级 OPC 和 Agent 软件。

## 显示范围

- 当前访问的管理端。
- 这个管理端配置的全部下级来源，以及各来源绑定的 Agent。
- 不主动发现其他管理端。46、58 各自显示自己的总览。

列表支持组件下拉筛选、来源/地址/版本搜索和手动刷新。显示版本号、发布编号、最后确认时间；“查看构建”展开提交号、源码摘要、构建平台等。组件报告启动信息时显示启动时间，否则显示“—”，不推测。

同类组件报告的版本/发布编号/提交/源码摘要不同，会显示版本不一致提示；这只是提示，不阻断采集、不自动升级、不自动切源，用户仍可自行修改业务配置。

## 在线与缓存

后台启动约 15 秒后开始读取，之后每轮结束约一分钟再次读取；页面每分钟刷新，可手动点击“刷新版本”。多个页面不会并行发起相同批次，连续请求有 10 秒节流。读取只调用状态/版本接口，不启动、停止、重启程序，也不发送串口命令。

- 在线：最近成功读取软件身份，不表示串口或站点正常。
- 不可达 + 离线/过期缓存：无法读取，保留上次成功版本及其原确认时间。
- 等待确认：管理端刚重启或记录超过 90 秒尚未重新确认。
- 版本功能不支持：对端没有提供可验证的版本，不以本地包版本替代。
- 未绑定：该来源尚未配置 Agent；下级 OPC 的版本仍独立显示。
- 来源已停用：不查询该来源下级 OPC；独立的 Agent 仍可查询。

只确认过一次的版本也会保存；来源离线、管理端重新启动后仍能查看。来源重命名保留记录；更换下级地址或登录身份、调整 Agent 绑定，不会把旧目标的版本当成新目标版本。删除来源同时清除缓存。

## 存储与接口

沿用管理端已有的内嵌 SQLite，不需要额外安装数据库服务。现有数据库本来就保存分组、来源、计算配置、账号及审计；本次只追加 `software_version_cache` 表，保存每个来源下级和 Agent 的最后确认身份，不保存实时采集值，也不记录版本历史流水。

`GET /api/v1/software-versions` 返回 `items`；加 `?refresh=1` 请求刷新。`build` 是对端报告的构建信息，`observed_at` 是上次成功确认时间，`checked_at` 是当前进程最近检查时间，`state` 和 `cached` 必须一起解释。接口沿用现有网页登录权限。

本功能不改变 OPC 业务点表、选源、计算、串口时序或安全策略。升级前应按现有发布方式备份数据库；旧程序不支持新的数据库 schema 时，需要配套数据库备份回滚，不能仅换旧二进制。
