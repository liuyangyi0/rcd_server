# 安全边界

## 部署假设

本程序按“受信任、隔离的工业内网”设计，不是可直接暴露到办公网、互联网或不受信任租户网络的多用户管理平台。部署至少需要：

- Windows 防火墙仅允许明确的上级 OPC 客户端、下级 OPC 服务器和运维终端；
- VLAN/ACL 隔离 4840 和 8080；
- 限制本机管理员和数据目录 ACL；
- 记录并审阅配置、命令和系统日志；
- 在发布前替换默认上级 OPC 密码。

## 已有保护

- 上级 OPC Secure endpoint 使用 Basic256Sha256/SignAndEncrypt；
- endpoint policy/mode 是精确白名单，未公布的组合会被拒绝；
- 下级密码在 Windows 上使用 DPAPI `CRYPTPROTECT_LOCAL_MACHINE` 加密保存；
- REST 不回传下级密码明文，只返回 `has_password`；
- 浏览器写请求进行同源检查，后端不开放 CORS；
- 管理 Web/REST、导出、metrics 与 SSE 使用管理员登录会话；密码保存加盐哈希，退出和改密使会话失效；
- 登录与改密有次数和并发限制；健康探针与下级日志接收维持独立通道；
- REST 修改使用 revision/`If-Match`，避免无意覆盖并发变更；
- SQLite 使用外键和事务；配置、命令写入管理/命令审计；
- Web 静态资源内嵌，运行时不从 CDN 加载代码。

## 明确不提供的保护

以下限制是当前实现/需求的组成部分，不能在部署说明中淡化：

- Web 目前是单管理员账号，没有 RBAC、多角色或 API key；
- HTTP 默认是明文 `0.0.0.0:8080`，程序内没有 HTTPS 终止；
- 除登录/改密外，不提供通用请求级速率限制；
- None/None OPC endpoint 允许 Anonymous；
- Basic256Sha256/SignAndEncrypt endpoint 也允许 Anonymous；
- 匿名 OPC Session 拥有 Browse、Read、Write 和 Call 权限；
- 上级服务端当前使用宽松的客户端证书校验设置，没有在本程序中实现受信任客户端证书白名单；
- 同源检查只约束正常浏览器语义；脚本访问管理接口同样需要有效登录 cookie，仍不能用同源检查代替身份认证；
- DPAPI machine scope 保护静态数据库密文，但同机高权限主体以及正在运行的服务仍能解密；
- 默认兼容凭据 `user1`/`pwd` 是公开弱默认值；
- 程序没有高可用、审计远传、防篡改日志或独立安全监控。

因此，“关闭跨域”和“使用安全 OPC endpoint”都不等于完成身份认证。若网络环境不能满足隔离假设，应先在外部增加反向代理身份认证/HTTPS、网络准入、VPN 或其他正式控制，再部署本程序；不要把 8080/4840 直接映射到互联网。

## 端口建议

| 方向 | 端口 | 建议规则 |
|---|---:|---|
| 上级客户端 → 管理程序 | TCP 4840 | 仅允许已登记上级 OPC 主机 |
| 运维终端 → 管理程序 | TCP 8080 | 仅允许运维网段；不允许互联网/访客网 |
| 管理程序 → 下级 OPC | 下级 endpoint 端口 | 仅允许已配置的下级 IP/端口 |

若必须经过反向代理访问 Web，代理应完成 HTTPS 和身份认证，并保留/规范化 Host、Origin 与 `Sec-Fetch-Site` 语义；写请求最终必须满足后端同源检查。上线前需要实际验证代理行为。

## 密钥和凭据运维

- `pki/rcd-manager-key.pem`：用 Windows ACL 限制到服务账户和管理员；备份时加密；
- `manager.db`：包含 DPAPI 密文、目录和审计，仍按敏感数据保护；
- `RCD_MANAGER_OPC_PASSWORD`：设置为机器级环境变量时，对本机管理员可见；定期轮换；
- 下级密码：通过 Web/REST 更新后不再从 API 取回；应保存在正式密码库中；
- 日志：当前实现避免主动记录密码，但 endpoint、来源 ID、错误和操作目标可能属于敏感运行信息。

## 威胁检查清单

- [ ] 4840 和 8080 的入站规则使用明确源地址，而非 Any；
- [ ] 管理主机没有通往互联网的端口映射；
- [ ] 默认 `pwd` 已替换；
- [ ] 上级客户端优先使用 Basic256Sha256/SignAndEncrypt；
- [ ] 已评估 Anonymous Write/Call 是否符合现场风险接受；
- [ ] 数据目录和安装目录 ACL 已核对；
- [ ] 证书指纹、有效期和 SAN 已登记；
- [ ] 数据库/PKI 备份已加密并完成恢复演练；
- [ ] 非浏览器 REST 调用方受网络和主机身份控制；
- [ ] 发布验证结果和例外批准已归档。
